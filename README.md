Vroom Vroom, APU Automotive Service Centre (APU-ASC)

This is a Java desktop application built for managing the APU Automotive Service Centre. 
The system supports 4 types of users: Managers, Counter Staff, Technicians, 
and Customers. Each with their own access rights and features such as appointment 
scheduling, payment collection, feedback, and report analysis.

Built using Java SE 21 with Java AWT & Swing for the GUI, and text files for data 
storage. No external databases are used.

## How to Run
1. Clone the repository
2. Open in any Java IDE
3. Run `Main.java`

## How to Clone
File > Import > Git > Projects From Git > Clone URL > Finish > You are all set!
